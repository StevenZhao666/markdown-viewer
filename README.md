# Markdown Viewer

桌面 Markdown 编辑器，分两个形态：

| 文件 | 说明 |
|---|---|
| `viewer.html` + `helper.py` | **完整版（v4.8.1）**：分屏编辑、可视化公式编辑器、块编辑、文件树、多标签页、主题色盘。配合本地小服务直接读写磁盘文件 |
| `MarkdownViewer-lite.html` | **轻量版（v4.1.5）**：单个 HTML 文件，双击即用，无需服务；保存走浏览器下载 |

---

## 完整版

### 怎么用

```
双击 OpenMarkdown.bat "(可选)要打开的 .md 路径"
```

脚本会检查端口 18520 → 按需启动 `helper.py`（Python 标准库，无第三方依赖）→ 浏览器打开 `http://localhost:18520/?file=...`。

也可以手动：`python helper.py`，然后浏览器开 `http://localhost:18520/`。

### 功能

- **分屏编辑**：左侧源码、右侧 KaTeX 实时预览（可开关）
- **块编辑**：双击段落进入编辑；Ctrl+Enter / Esc 完成；编辑框与预览双向滚动同步
- **公式编辑器（可视化，v4.8.x）**：
  - 模板按钮构建公式树：分式 / 根号 / 上下标 / 积分 / 求和 / 累乘 / 极限 / 矩阵 / 组合数，另有概率统计面板
  - **单击槽位选中** → 点模板即嵌入该槽，可连点连续嵌套；选中一段内容再点模板 = 自动包裹（`\sqrt{}` + 选中 `a_n` → `\sqrt{a_n}`）
  - 键盘直输（选中槽变文本、Backspace 删节点）；**双击**节点进源码编辑
  - 未填的槽位生成空 `{}`（不产生 `?` 字面量），预览即所得
- **符号工具栏**：常用 LaTeX 符号 + 分类面板（常用 / 微积分 / 线代 / 希腊字母 / 运算符 / 函数 / 概率统计）
- **KaTeX 本地化**（`lib/katex`，离线可用，无 CDN 依赖）
- **多标签页**：新建 / 关闭 / 双击标签改名（同步磁盘）
- **文件树**（侧栏浏览文件夹内的 .md）、**目录 TOC**（视口高亮 + KaTeX 渲染标题公式）
- **主题色盘**：背景 / 主题色 / 文字色 / 字体即时切换并持久化；派生色随明暗自适应（深浅两套都可用）
- **笔记级渲染修复（v4.7.x）**：正文裸 `<` 自动转义（不再吞公式）、表格单元格内 `$...$` 与 `|`、`$$` 显示公式块、`\$` 字面美元、标题里的公式进目录等

### 验证方式

`tests/` 下有回归用例（`t_cases.md`：裸 `<`、`^*`、表格含 `|`、`$$`、代码块、`<details>`、`\$`、标题公式、末尾无换行表格等）与对应的 node 测试脚本；渲染相关改动先跑它们。

### 已知问题

- 表格编辑功能不完整
- `helper.py` 无鉴权，仅绑定 127.0.0.1（本机使用）

## 轻量版（MarkdownViewer-lite.html）

单个 HTML 文件，双击即用，无需安装、无需构建。

- **实时预览**：左侧编辑、右侧预览，输入即时渲染
- **LaTeX 公式**：内置公式编辑器（分式、积分、极限、上下标、矩阵、求和/累乘等），自动生成 LaTeX 源码
- **KaTeX 渲染**：`$...$` 行内公式与 `$$...$$` 块公式（走 CDN，首次打开需联网）
- **符号工具栏**：常用数学符号分类面板，点击即插入
- **本地文件操作**：打开本地 .md 编辑，保存为文件下载

```
下载 MarkdownViewer-lite.html → 双击用浏览器打开
```

## 目录结构

```
viewer.html              # 完整版主程序（单文件 HTML+CSS+JS）
helper.py                # 本地服务：文件读写 API + 静态文件（端口 18520）
OpenMarkdown.bat / .ps1  # Windows 启动入口
MarkdownViewer-lite.html # 轻量版
lib/katex/               # KaTeX 本地化（css/js/字体）
docs/程序结构详解.md      # 代码地图：模块、公式编辑器 Atom 树、改动指引
tests/                   # 渲染回归用例
backups/                 # 历史版本备份（不入库）
```

## 技术说明

- 纯前端实现（完整版 + 一个 Python 标准库小服务），无构建步骤
- 代码组织在 `docs/程序结构详解.md` 中有逐模块说明
